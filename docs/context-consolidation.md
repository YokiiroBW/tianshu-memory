# 会话经历整理与人物归纳

普通新学习只使用 `memory-extraction` schema 6。沿用原后台队列：先收集有 SID/账号和当前授权范围的真实材料，封段后一次整理参与者各自的表达。其他人的发言与已送达的 BOT 回复作为上下文，不自动变成目标人物的经历。没有充分个人材料时可以返回空记忆或不更新画像。

## 当前入口

1. `/internal/v1/memory/candidates/materials` 接收真实前台事件或受权观察来源，捕获原话和必要作者元数据，不创建单条消息整理任务。
2. `/internal/v1/memory/candidates/segments` 固定材料、目标人物与完整上下文，复用 jobs、memory_batches 和来源账本。每段最多 8 个目标、32 个完整成员及 48KiB 正文。
3. `/internal/v1/memory/candidates/process` 只接受 `extraction_schema:6`，用同一 job/batch 读取固定输入、提交模型结果或查询真实完成回执。未知结果不能重新选材。schema 3/4/5 请求明确拒绝，不再恢复旧单人任务。

`/internal/v1/memory/turn-commits` 仅保留为当前受权事件日志/消重端口，返回 `candidate_job_ref:null`，不创建或提交候选。生产整理通过 materials 内部复用相同 consume 方法登记事件。

未安装当前 `memory_segment_schema` 的环境明确不可用，不后退创建旧单人候选。显式部署准备仍沿 `migrate-memory`、`migrate-observations`、`migrate-qq-aliases`、`migrate-segments` 安装现有表与来源检查点；业务请求不自动改库。

## 记忆浏览与存储升级

存储元数据版本为 `memory_segment_schema=2`，自动整理的公开协议仍为 schema 6。既有 `migrate-segments --backup <新备份路径>` 在备份后升级原 `memory_segment_items`：追加原话时间的数值排序键和精确替代引用，旧记录保留，重复执行返回已安装。没有增加第二份记忆库。升级在停止写者的既有发布步骤执行；业务请求不自动升级，未升级的已安装存储不会被当作当前布局启动。

本人浏览沿用 `/memory/browser/overview` 和 `/memory/browser/records`。概览在同一来源边界内直接聚合最近 7/30 天的有效记忆、未结束约定和当前画像，不调用模型；记录按原话时间和记录 ID 稳定分页，响应裁剪继续使用同一游标。仅扫描部分记录时明确返回不完整标识。考虑中、已确认与进展未明的约定可列为未结束，日期经过不能自动标记完成；画像单独呈现。

替代引用仅用于解释本次真实更新，既不成为新事实来源，也不改变既有上下文依赖。旧上下文撤回后，依赖它的派生记忆仍须隐藏。浏览详情只返回当前授权内容与本人原话，页面在授权仍有效但内容版本变化时也重新读取并清除旧展示。

## 模型整理与归属

输入包括完整成员、真实 speaker/source scope，以及每个目标本人的 `new_member_ids`。输出必须覆盖全部目标，并逐人返回自己的覆盖成员、记忆和可空画像。记忆携带种类、状态、重要度、保留周期和本人的原文成员引用；计划、约定、发生经历按输出字段表达，不由本地场景词规则推断。

提交前检查人物集合、本人新输入覆盖、引用归属、既有记忆版本与来源当前性，整段原子提交。模型不能把 B 的原话引用给 A，也不能使用上下文替代 A 自己的新输入。结构和引用校验不能保证模型逐句理解正确，证据不足应不生成记忆。

画像只在有足够经历基础时提供整理输入，与该段记忆共享一次模型调用。已有来源的历史个人原话用于归纳；BOT 建议不能成为用户已经完成的经历。画像 CAS 冲突不撤销已经合法保存的个人记忆。

## 来源与生命周期

摘要、画像和原话沿用 groups/records/lineage、write ledger、文档和向量索引。所有完整来源依赖仍受来源屏障约束。撤权、来源撤回、身份绑定变化或显式忘记使派生内容失效，也阻止晚到提交或向量重建复活。普通读取遇到本轮已持久化撤回的旧自动材料时排除该材料，显式原文检查仍严格。

配置继续复用：

```json
{"memory_consolidation":{"ttl_days":{"low":7,"normal":30,"high":180}}}
```

模型选择 short/medium/long，分别对应以上三档。有效期依据本人新输入的实际发生时间计算，重复引用旧上下文不续期；未完成约定的明确截止时间可延长其保留期。自然到期仅退出日常 current 候选，history/mixed 仍需验证权限与来源，不写 suppression。显式删除继续通过现有记忆修订或 episode 遗忘接口执行。

## 查询与查看

v2 查询复用事实/经历与 episode 两类预算。`retrieval_mode=context` 提供带来源的正向对话材料，保持不完整标记；factual/history 请求继续使用各自范围与证明。verify/prepare 仍在模型和发送边界核对选中材料的精确版本与完整来源。人物范围和群范围不因文字相似、昵称或图布局扩大。

不增加第二个记忆数据库、队列或来源权威。群图与页面视图读取现有记录和统计；用户记忆与 BOT 自身记忆保持独立领域。
