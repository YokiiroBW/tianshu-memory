## 实现与复用位置

- `memory_context/scopes.py` 凝聚原 `authorized_scopes/checks/verified_scopes`，没有旧转发层。
  私聊显式关联仍沿原直接关联、binding/version 与独立来源核验路径。只有正式
  SourceAuthority 的群 query/history 使用内部 `group_read`，wire 没有新授权字段。
- `SourceAuthority.coverage/barrier/sync*` 在同 actor、原 audience=group、同 conversation
  覆盖现有 admissions 与来源，包括历史、撤回及负面状态。viewer 始终是实际 requester；
  owner admissions、当前 binding/grant、Core/Platform head、CAS 和原六次 fresh revision
  调用保持。不是逐 owner 伪造 origin 或新开 operation，也不借管理员/关系/画像审核授范围。
- `group_rows/group_candidates` 在读取 record payload 前要求每组全部 lineage 属于真实
  owner 的原群 scope，admission 与 physical 的原群边界一致。随后复用
  `eligible_groups` 的来源先行、完整组、shared_projection、projection 版本及
  `_units(subject_person_id == 实际 owner)` 校验。新的可信 `scopes_by_group` 保留 PG
  512 分批/current_many 路径；旧 select/exact 默认规则没有扩大。
- 初始群候选使用统一最多 4096 组窗口，姓名唯一性在全部 category 上核对，之后才按
  selection/主题过滤。`recall_relevance.named_owner` 只用已授权、当前有效的
  `identity.name` 精确称呼和记录 owner 连接；evidence 类姓名同样可用。唯一匹配时携带
  原完整姓名组作为必要见证，与目标组共同 fit；见证或目标放不下就不保留精准归属答案。
  同名、无可靠绑定或截断窗口不能猜 owner，不新建身份目录、RPC 或模型。
- `recall_language` 复用既有 query/引号处理；明确自指只取 requester，引用他人原话内
  “我的”不会成为 requester 身份。普通本人宠物问题不因本次姓名能力夹带姓名记录。
- `MemoryService._fit_groups` 复用原单位/完整组/字节预算；群响应最多 requester 加
  16 个实际返回 owner，跳过整组并显式 budget/incomplete。scope_checks 只列真正 fit
  的 owner，不枚举群成员。零预算 known 和 history 只重新证明所观察集合各 owner 的
  当前可读原群完整组、身份与版本，未知/失效 owner 拒绝，集合不作为授权输入。
- `rank_groups` 只对 eligible 的 scope 集合做参数化 256 分块索引读取，保留
  `(record_id,record_version)`、候选文档和原 BM25。query 把最初完整授权组 ID 集合传给
  原 `reference_terms`：合法同群旧别称仍可找到新值；未通过完整 lineage 的旧组在读
  payload 前退出，不能从混合私聊来源借 tokens 影响群排名。legacy 默认不变。
- time_range 仅按目标事实原消息 sent_at 筛选、读取 target selectors 与统计缺时；当前
  姓名是归属辅助，声明时间可以更早，不能据此称该姓名声明发生在查询时段。
  witness 仍在整轮来源/head/revision、完整预算及返回前 `_verify_retrieval` 中核验。
  远程 rank/time I/O 后重新进入同一 group_read fresh 边界，按完整有界授权域复用
  resolver 重核姓名当前性、全群唯一性、原 owner 与必要 witness。无 DML 的 valid_to
  到期/他 owner valid_from 生效同样拒绝；新其他 owner 写入不能靠 requester 版本未变穿过。

如实 skip；协调者可沿既有 `postgres_store` 使用显式 `TIANSHU_TEST_POSTGRES_URL`，运行：

```powershell
python -m pytest tests/test_group_context.py -k postgresql -q --basetemp <新隔离目录>
```

私聊/跨群/跨 actor 拒绝、零预算/history、撤源/撤权/binding、同名/跨 category/截断、
完整预算、原 owner、单批 payload/排名 SQL、合法与非法旧引用，以及 rank/time 后 fresh。
本执行者未执行原生 PG；不能以本地 SQL/SQLite 或 skip 称原生通过。真实 PG、新旧联合
消费者及真实模型冷召回由协调者后置；本卡不称真实 150 人使用或生产验收已完成。

4096 是统一元数据/姓名唯一性窗口，不是全部群历史证明；截断显式 incomplete，必要时
保守少召或澄清，history_complete 始终 false。没有唯一、当前、可完整返回的姓名证据时
不能仅凭问题字面挑 owner；普通群事实查询仍可返回原 owner 的有据记录，消费者须保持
真实归属并按证据表达，不能补写来源未给的姓名、引文或事实。
