## 已实现

可运行 FastAPI HTTP 端点、Python 应用层与 SQLite/WAL/FTS5 实际存储。人物 resolve/register 保持同账号群私同 person_id，昵称变化不新建人；跨平台不按昵称合并。每服务独立凭据、当前来源解析、本人绑定及精确 scope 验证；幂等键持久化并拒绝异负载，重试仍重新授权。

版本化完整语义组保存主体、条件、否定、时间、不确定性、现实/虚构及来源。显式共享兴趣由 memory 签发独立 projection_ref/version，私聊来源血缘留服务端，pending 原文保持 pending。关键词检索只用词项/中文双字，排除时间、问候与通用问句作为独自匹配依据；授权过滤后，每个完整语义组组成一个 FTS 文档，按查询词项覆盖数、实际 BM25 得分排序，再做整组预算选择，ID 只作最终平局顺序。field:/item: 通过 SQL 元数据索引先缩小候选，只读取目标组正文、完全跳过 FTS。完整组同取同舍，不返回隐藏私人记录数量。

更正/遗忘在同一事务内更新权威版本/墓碑、整个关联语义组/投影、scope_version、来源 epoch 与 outbox；无法同步重建的语义立即 invalidated。旧索引、旧候选和未送达失效通知不会恢复旧内容。v1 不允许恢复墓碑，tombstoned 上 correct 返回 invalid_input/400，即使版本正确且有新证据/确认；拒绝不改变记录、历史或确认，原幂等 forget 重放仍返回真实 tombstoned 回执。无私密响应缓存；零预算仍执行当前身份/精确范围/版本核验，随后只返回空结果，不扫描正文、不建临时 FTS，支持 companion 发送前复核。

turn_committed 经 companion 服务发布权限与当前来源核验，原子去重 event_id 和 turn/input_revision，可靠创建 candidate_job_ref，confirmed_memory_written 恒 false。内部审核可提交完整语义组或跳过；job/source-version ledger 去重记录和关系累计；混合虚构逐来源保留。队列上限、失效释放容量、outbox 未确认重读、重启继续均有测试。没有调用模型或后台自动假确认。

## 未完成与集成需要

1. 生产来源核验、短期来源实际签发/撤销、确认签发及 Chat Audit 原文回读未接通。默认来源后端不可用；唯一附带后端明确 local_fixture，`/health` 显示 raw_source_read unavailable。真实 wire 若需扩展，先协调发布，不猜接口。
2. 首次 register 可接受来源 person/conversation null；select 可从当前账号补 person，但不信任任意会话 ID。按协调者确认的现有合同闭环，接入方仅在收到可信核心 ingest_response 后记录 verified channel→conversation，issuer 后续返回具体会话；未解析时 503、明确不匹配时 403。这部分跨产品 L0 前置尚未联合运行，不新增共享 wire。
3. 事件无需新增 X-Origin-Assertion-Ref；只用已认证 companion、服务器 exact event_scopes 与当前来源。发布权限配置需在集成时由服务端建立，不能从 event payload 自动生成。
4. 自动候选提炼、自动完整语义重建未实现；当前经审核结构化语义通过本服务应用层提交。没有每句话强制 LLM 总结、没有任意模型直接确认写记忆。更正暂取原子 invalidation 路线，旧句不能继续召回；重新形成可用记忆需要新的有效来源和完整审核语义。
5. 跨次查询累计预算由 companion 扣除既有装配、去重后传剩余额度；memory 执行每请求预算。零预算校验不是分布式原子发送授权。当前 token 估计严格受字节/条目上限约束，不冒充目标模型实际消耗。
6. PostgreSQL、真实嵌入/向量、开放域语义评测、双账号证明关联、跨人物/全群画像、真实外部渠道及 L0/L1 未完成。SQLite 只证明本地关系存储能力。词项/中文双字门槛会漏掉单字主题和只有时间的含混问题；双字巧合及间接表达仍有无关/漏召回风险，预算充足时可能返回多个部分主题匹配。现有本地库需执行 rebuild-index 更新切分，不以新排序宣称语义模型已接通。
7. 内部 outbox 可持久重读/确认，但生产投递器、owner aggregate snapshot 与 memory.revised 共享 wire 尚待后续发布。遗忘是不可召回墓碑和服务端审计历史，未实现物理擦除/备份清除。来源重复包含部分新内容时保守整 job 去重，未自动拆分。
