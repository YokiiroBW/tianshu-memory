# TS-327：原 browser 的动态真实群委托

基线 `a2de620c676a24d7c08bb33ef3f1be2488b71666`，分支
`codex/group-modes-20261027`。本卡只有一个生产文件 `browser.py`，不修改
Memory 来源规则、表、合同或用户/actor 记忆域。

原 reader 可显式配置 `allow_runtime_groups: true`，默认仍 false。此字段只把新增
群 CID 的登记委托给原受信 Platform origin owner：当前 verified_account 必须与
reader 账户精确一致，fresh allowed_scope 必须等于请求，群 scope 的 operator person
必须与该 reader 原 actor 模板相同。actor 仍须为原静态 actor，或原 reader/caller
两个 runtime-role flag 加当前有效 RoleGrants。错账户、人物、角色和未登记私聊不扩权。

复用原 `_registration`、远端 source barrier、barrier 后当前 origin/配置复验、
最终读事务和 forget 负态。新增群是否真实存在及其 canonical CID 的证明仍由
Platform 原 catalog/Core channel/WEB origin 负责，不能由浏览器自报。
