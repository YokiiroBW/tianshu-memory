# M1-1：向量二进制

基线 bdae8c1。array 标准库实现 float32 小端编码、读取与点积，无新增依赖。新装及显式 migrate-retrieval 迁移同时覆盖 SQLite/PG；迁移独占备份数据库和 source-guard，分批转换旧向量；JSON 列双写保留，未迁移库继续用 JSON。

二进制损坏沿现有写事务清理，CAS 同时绑定原 JSON 与二进制值；readonly 仅准备数据。PG JSON 备份的派生二进制副本留 null，原 JSON 向量完整保留，可离线恢复/重建；SQLite 备份完整保留二进制。PG 导入比较支持二进制。

验证：binary_vectors 3 通过（混读、误差 <1e-6、真实 Store 迁移、成对备份、幂等）；query_vector_boundary 50 通过（真实回环 TLS、前后来源核验、只读边界、失败降级）。旧腐坏测试已改为损坏实际读取的二进制列。

memory_v2 初轮 21 项旧语义失败：仍断言已退役 typed fact/known_facts；另 2 项二进制腐坏夹具已修正并定向全通过。抽取原 57a1a14 源码重跑三个代表失败（6 参数实例），同样失败，未修无关夹具。其余适用结果复用，不称完整套件全绿。首轮缺 TLS tooling 已按既有文档设置 TIANSHU_TEST_CERT_PYTHON 解决。真实 PG 迁移将于隔离库及发布停写时验证，尚未计作通过。
