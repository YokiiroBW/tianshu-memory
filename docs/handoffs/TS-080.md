## 目标与实现

资料进入独立项目知识域，不转成聊天 P/A、Core receipt、SourceAuthority 或人物画像。复用 Store SQLite/WAL、原有词法规范化/FTS5 与 source-guard；八张权威表的写入均增加 source_revision。显式迁移先备份，旧恢复库被 guard 拒绝，既有历史来源权威不改写。

`KnowledgeApplication` 和独立 CLI 支持单个本地文本/Markdown/代码/HTML 文件或登记 URL 的导入、查询、导入状态、逻辑删除、明确项目记忆写回、短恢复与缓存检查。稳定项目/来源/文档标识、raw hash、版本、完整块行引用和幂等结果持久保存。原始字节、HTML 可见文本、显式项目状态分别存储；状态历史保留。

默认完整来源为一个语义块；更细粒度由显式审阅的覆盖行组和依赖闭包给出，保留条件、否定、因果和必要上下文。无模型也能保真存储与词法检索，不声称通用语义抽取或向量搜索。预算不足整块遗漏，不截断；query 上限 32 KiB，recover 同上且当前状态和全部证据整体装配。每次读取核对被引用文件 hash；删除/替换/状态更新/文件变更使旧证据或恢复包不可用。服务端独立密钥签名，客户端知道自己的凭据也不能给篡改包重新签名。

目录只接受配置登记且单文件只读，不递归扫描或整理 NAS；路径越界、junction/symlink 越界、隐藏/凭据/运行/模型目录以及不支持格式拒绝。URL 每跳精确登记、公网 IP 固定 TLS 主机名验证、1 MiB、15 秒网络期限、3 次重定向、明确类型与编码边界，不执行脚本或跟随页面链接。导入可预期失败记录状态；刷新失败停止旧 URL 快照召回。

MCP 使用官方 FastMCP stdio，无自造协议框架。七个读写分离工具；启动时指定客户端，调用时根据私有配置和独立凭据核验精确 project/operation，配置撤权实时生效。默认不启用或注册任何客户端。Hermes 示例已对照官方 `mcp_servers` 文档，实际子进程命令使用本产品入口。

## 限制、成本与下一步

1. `docs/candidates/project-knowledge/v1` 是请求 schema/实例候选；根合同待协调审查发布，Hermes 真客户端工具发现/用户确认/缓存 check 待联合验收。官方 SDK 通信通过不等于 Hermes 已接入。
2. 只支持已说明 UTF-8 文本类型；PDF/Office/图片等明确 unsupported。无 AI 整理入口、自动全局踩坑晋升或人物共享；原文与显式状态写回可独立使用。
3. URL 是最近显式导入快照，不承诺远端实时状态。系统 DNS 解析的 OS 超时在 15 秒网络期限之外；不声称进程硬总超时。导入在串行 Store 事务内，网络慢请求可能占用写锁；查询最多 128 候选但仍需读取当前文件 hash。适合小资料库，无大库吞吐或公网可用性成绩。
4. 完整块/证据超预算会明确遗漏，不能保证每次都返回状态。文件 hash 是读取时刻的检查；客户端必须在缓存复用前 check，不能让历史状态覆盖当前用户/工作树事实。
5. 配置和注册资料目录属于可信本地操作者边界；文件名阻断规则不是内容 DLP。删除是索引墓碑，原始文件和历史审查版本保留，不宣称物理擦除。
6. 暂不提供项目登记变更/目录搬迁和旧库恢复批准；配置变更失败关闭。迁移上线需停写及备份/恢复审查，未操作任何真实数据库。
