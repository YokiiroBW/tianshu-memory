# M3-1：保守事件状态投影

基线 ce44f93。新增 event_projection（纯槽位投影）和 memory_events（来源依赖、存储、迁移与私有读取）。memory_event_refs/state 均为可重建派生，不进 source_revision 触发器。只沿同完整 scope、同事件族的明确 prior_refs 关联；更新/取消必须匹配事件、属性、参与者、表达资格和精确引用，不按写入时间覆盖其他主张。转述进入争议槽，不变成第三方本人承诺；同属性无明确更新关系保留并列。

复用现有结构化 kind/state：约定、显式行动状态，以及明确 replace 的想法/偏好修订；一般经历或无结构自然语言不强行归类，不从相似度合并事件/人物。observed_at、valid_from/valid_to、recorded_at 分别保存在声明中；原合同无 valid_from，未知值保留 null，不用观察时间冒充生效时间，不扩公共合同。

投影读取复用原 publisher 范围、SourceAuthority operation、现有 permits 交集和精确记录/source 版本；任一必要来源、抑制或记录失效，则整体不可用。读前捕获的版本若并发改变也不复用。私有 /memory/candidates/event-state 返回状态，事件 id 不授予权限。当前检索只在完整投影基础全部仍在原授权候选中时关联已有完整选材单元；各单元仍沿原两次边界核验，不把派生槽位当成第二事实源或新 bundle 字段。

验证：五步场景、第三方报告、乱序输入、实际 HTTP 保存/replace/读取、来源撤回整体失效、跨 owner 拒绝、时间轴和三种族的 6 项实例均通过；和完整同窗/h03 定向选材共 29 通过/1 既有范围跳过。最初 SQL source_scope 别名错误和撤回测试替身不完整均已修正，失败日志保留。另 3 项 MMR/原子单元测试复用通过结果。无真实模型/QQ。

回滚：revert 本卡，派生表可保留，原记录/JSON/授权/guard 不改。投影不回填任意旧自然语言事件，也不声称替代真实回答质量验收。安装 migrate-events 需停写与成对备份。
