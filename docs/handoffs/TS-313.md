已确认来源负态持久失效依赖 episode；无关 owner 水位变化不抹除仍 current 的精确来源。

首次命令回执原包不可改。语义相同的写重试可回本次 request_id；get_receipt 返回首次包。
撤回和已失效身份不能由晚到 append 复活。HTTP 超时后实际 worker 仍持有其准入，
关闭时等待实际 worker 退出再关闭连接池和独立 Store。
